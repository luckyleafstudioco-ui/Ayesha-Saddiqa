# PennyWise - Expense Tracker

A personal finance dashboard to track income and expenses in PKR.

## Features
- Add income and expense transactions
- Categories: Food, Transport, Shopping, Education, Bills, Health, Salary, Freelancing, Other
- Total Income, Total Expenses and Available Balance summary
- Filter transactions by All / Income / Expenses
- Delete transactions
- Data saved in the browser (localStorage)
- Fully responsive — works on mobile

## How to run
Open `index.html` in any browser, or view the live GitHub Pages site.
